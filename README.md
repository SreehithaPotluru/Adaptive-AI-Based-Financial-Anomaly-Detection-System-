## Abstract

The Adaptive AI-Based Financial Anomaly Detection System for SMEs is an AI-powered system designed to identify unusual and potentially suspicious financial transactions in Small and Medium Enterprises. Traditional financial monitoring systems often rely on fixed rules and thresholds, which may not effectively detect changing financial patterns. The proposed system uses machine learning, particularly the Isolation Forest algorithm, to learn normal transaction behavior and identify anomalies based on transaction amount, frequency, timing, vendor, payment method, and other relevant features. An adaptive mechanism allows the system to adjust to changing business patterns and incorporate new transaction data and user feedback. The system provides anomaly scores, risk levels, alerts, and a dashboard to help SME administrators monitor financial activities and investigate potential irregularities.
